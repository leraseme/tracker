# Как выложить трекер в интернет и установить как приложение

В папке лежат готовые файлы приложения:

- `index.html` - само приложение
- `manifest.webmanifest` - название, цвета и иконки приложения
- `sw.js` - работа без интернета
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` - иконки
- `netlify.toml` - настройка для Netlify (для других хостингов не нужен)

Все файлы должны лежать вместе, в одной папке, без вложенных папок.
Приложению нужен адрес с https (так делают все перечисленные ниже хостинги),
иначе оно не установится как приложение.

---

## Вариант 1. Netlify (самый простой, 3 минуты, без установки программ)

1. Зайди на https://app.netlify.com/drop (можно войти через Google или e-mail).
2. Перетащи **всю папку** `tracker-app` в окно браузера.
3. Через несколько секунд получишь адрес вида `https://что-то-там.netlify.app`.
4. В настройках сайта (Site configuration → Change site name) можно поменять адрес на красивый,
   например `moy-tracker.netlify.app`.

Чтобы обновить приложение позже: открой сайт в Netlify → вкладка Deploys → перетащи новую папку туда же.

## Вариант 2. GitHub Pages

1. Зарегистрируйся на https://github.com и нажми New repository. Назови его, например, `tracker`, выбери Public.
2. В репозитории нажми Add file → Upload files, перетащи все файлы из папки (сами файлы, не папку) и нажми Commit changes.
3. Открой Settings → Pages. В разделе Branch выбери `main` и папку `/ (root)`, нажми Save.
4. Через 1-2 минуты сайт откроется по адресу `https://твой-ник.github.io/tracker/`.

## Вариант 3. Cloudflare Pages

1. Зайди на https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets.
2. Назови проект, загрузи файлы из папки и нажми Deploy.
3. Адрес будет вида `https://название.pages.dev`.

## Как установить на телефон или компьютер

- **iPhone (Safari):** открой свой адрес → кнопка «Поделиться» → «На экран "Домой"».
  Установка работает только через Safari.
- **Android (Chrome):** открой адрес → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- **Компьютер (Chrome, Edge):** в адресной строке справа появится значок установки. Нажми его.

После установки трекер открывается отдельной иконкой с бордовым цветком, без адресной строки.

## Важно про данные

Данные хранятся **на устройстве**, в браузере, и сами между телефоном и компьютером не переносятся.
Чтобы перенести их или сделать запасную копию, внизу приложения есть блок «Копия данных»:

1. На старом устройстве нажми «Сохранить копию» - скачается файл `tracker-backup-дата.json`.
2. Перешли этот файл себе (в мессенджер или на почту).
3. На новом устройстве нажми «Загрузить копию» и выбери файл.

Данные сотрутся, если очистить данные сайта в браузере или удалить приложение,
поэтому иногда сохраняй копию.

Данные из версии внутри Claude сюда сами не перенесутся: в той версии копии нет,
так что цели и планы придётся внести заново (это пара минут).

## Если после обновления ничего не поменялось

Приложение запоминает файлы для работы без интернета. Закрой его полностью и открой снова
(иногда нужно открыть дважды). Если не помогло, в браузере обнови страницу с очисткой кеша
(на компьютере Ctrl+Shift+R).
